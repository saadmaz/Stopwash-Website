# Routes

This app uses [TanStack Router](https://tanstack.com/router) file-based routing. Each `.tsx` file in this directory defines a route, and `__root.tsx` is the application shell that wraps every page.

## Naming conventions

| File                     | URL                                                                  |
| ------------------------ | -------------------------------------------------------------------- |
| `index.tsx`              | `/`                                                                  |
| `about.tsx`              | `/about`                                                             |
| `services/index.tsx`     | `/services`                                                          |
| `services/$slug.tsx`     | `/services/:slug` (dynamic segment)                                  |
| `posts/{-$category}.tsx` | `/posts/:category?` (optional segment)                               |
| `files/$.tsx`            | `/files/*` (splat, read from the `_splat` param)                     |
| `_layout.tsx`            | Pathless layout route that renders its children through `<Outlet />` |
| `__root.tsx`             | Application shell; must render `<Outlet />`                          |

## Generated files

`src/routeTree.gen.ts` is generated by the router plugin during `dev` and `build`. Do not edit it by hand; commit it alongside route changes.
