# Security Policy

## Supported versions

Only the version currently deployed to [stopwash.lk](https://stopwash.lk), built from the `main` branch, receives security fixes.

| Version | Supported |
| --- | --- |
| Latest release on `main` | Yes |
| Older releases | No |

## Reporting a vulnerability

Please **do not** open a public issue, pull request or discussion for a security problem.

Report it privately by email to **[hello@stopwash.lk](mailto:hello@stopwash.lk)** with the subject line `Security report`. Include:

- a description of the issue and its potential impact,
- the affected URL, page or file,
- steps to reproduce, or a proof of concept,
- any suggested fix.

### What to expect

| Stage | Target |
| --- | --- |
| Acknowledgement | Within 3 business days |
| Initial assessment | Within 7 business days |
| Fix or mitigation | Based on severity; critical issues are prioritised immediately |

We will keep you informed throughout and let you know when the issue is resolved.

## Scope

In scope:

- the website at stopwash.lk and its subdomains,
- the enquiry and franchise application forms,
- the source code in this repository.

Out of scope:

- denial-of-service and volumetric attacks,
- social engineering of STOPWASH staff or customers,
- findings from automated scanners without a demonstrated impact,
- third-party services (for example Supabase or Cloudflare) — report those to the provider.

## Safe harbour

We will not pursue action against anyone who reports a vulnerability in good faith, avoids privacy violations and service disruption, does not access or modify other people's data, and gives us reasonable time to fix the issue before disclosing it.
